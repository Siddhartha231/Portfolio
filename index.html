Daymark

Desktop task manager

Java 21, JavaFX, SQLite, JDBC, Maven, JUnit

Daymark started as a console program. I rebuilt it as a real desktop app to practice a layered architecture: add, edit and delete tasks, filter by priority, search by text, and see anything overdue in red.

The interface only ever talks to a service layer, and storage sits behind a repository interface, so the SQLite backend can be swapped without touching the rest of the app. JUnit tests cover the domain, service and database layers, including malformed dates in stored rows.

ui
Main window and the add/edit dialog
service
Validation rules and done/undone logic
persistence
SQLite connection and the SQL itself
domain
Immutable Task and Priority, no dependencies

FocusLog

Command-line Pomodoro tracker

Python, SQLite, argparse

FocusLog times study sessions from the terminal and logs each one to SQLite with its subject, duration and start time. By default it runs four 25-minute rounds with 5-minute breaks, and you can change all three.

Stop early with Ctrl+C and the time you finished is still saved. Daily and weekly summaries show where the hours went, by subject and by day.
